Other platforms

Nix runs on most Linux distributions beside their own packages, so on Debian, Fedora, Arch and the others you can install Nix first and then the app. Nix fetches a release's app ready-built from Dassie's cache, or builds it from Dassie's source, as the install page says.

Packages for other Linux distributions (AppImage, .deb and Flatpak), the app in the release mirror's signed flake, updates from inside the app, and the app for macOS and Windows are not there yet. Each gets its page here once it arrives. What's next

Until then

On a computer the app does not run on yet, you can still have a node of your own:

  • On a server, with a public address and a domain name: Quick Start installs a node there, and you use its wallet from any browser.
  • On a Linux machine without a public address, as a small home server: the same dassie binary runs there as a periphery node, reached the way the desktop app is. A server without a public IP shows how.

Pick your setup compares them with the desktop app.

Apps for a node elsewhere

The desktop app runs its node inside itself. A different kind of app is planned too: one that runs no node, and reaches yours on another machine. Your node can already pair such apps, with dassie pair, and serves them through the nodes it is connected to, its uplinks.

The apps themselves, a remote mode of the desktop app and a mobile app, are not there yet. What's next
