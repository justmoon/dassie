What is Dassie?

A peer-to-peer network which can transfer tiny amounts of money quickly and cheaply.

Get Started Try STREAM See the code
Dassie is not a blockchain. Payments are routed like packets through the network and are not stored. The only state the nodes share is the link state they route by.

Scalable

Dassie can handle very large numbers of very small payments, and it scales horizontally: its capacity grows as more nodes join the network.

Currency-neutral

Dassie handles currency exchange and routing for you. Hold the currency you like and still pay everyone else on the network.

Ledger-neutral

Nodes settle with each other on existing ledgers; today that is the XRP Ledger testnet. Dassie is based on Interledger, so it can work with any payment system that has an open API.

Under development

Dassie is still early in its development and not ready for real money. If you are still interested, give it a try.
