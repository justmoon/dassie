Early days

Any currency. Any ledger. Anyone.

Dassie is a peer-to-peer payment network you run yourself. Your node peers with a few neighbors, keeps its own books and settles on a shared ledger. Nobody sits on top.

$curl --proto =https --tlsv1.2 -sSf https://sh.dassie.land | sh # Then set up the node: sudo dassie init
Quick Start Try STREAM

Find your neighbors

Your node meets the network through its bootstrap nodes, and picks a few peers of its own.

Keep your own books

It records what each peer owes it, and settles with them on a ledger they share.

Earn your keep

Set a small fee for each payment your node carries for others. It updates itself every day.

Open on every side.

Any currency

Dassie handles currency exchange and routing for you. Hold the currency you like and still pay everyone else on the network.

Any ledger

Nodes settle with each other on existing ledgers; today that is the XRP Ledger. Dassie is based on Interledger, so it can work with any payment system that has an open API.

Anyone

Anyone can run a node. The network handles very large numbers of very small payments, and its capacity grows as more nodes join.

Dassie is not a blockchain.

Payments are routed like packets through the network and are not stored. The only state the nodes share is the link state they route by.

It's early, and that's fine.

Few users and few ledgers so far, with more every day. Dassie is not ready for real money yet. If you are still interested, give it a try or read the code.
